# Project workflow

- Follow the official track brief linked in README.md. Keep the submission reproducible on the published scorer.
- Use small, reversible, scoped commits with descriptive prefixes such as chore:, feat:, fix: or docs:.
- Stage explicit paths and preserve unrelated changes. Check the diff and run relevant validation before publishing.
- Before opening a pull request, run the local-pr-autoreview skill. Keep review local and use a focused PR against the correct base.
- Keep organiser downloads, local datasets, generated outputs and credentials out of the public repository.
